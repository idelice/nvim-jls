*jls.txt*  Neovim integration for JLS

*jls*

INTRODUCTION~

*jls-introduction*

nvim-jls provides Neovim integration for JLS (Java Language Server), with
OS-aware launcher resolution and stable root detection.

REQUIREMENTS~

*jls-requirements*

- Neovim 0.9+ (0.10+ recommended)
- Optional: nvim-lspconfig

SETUP~

*jls-setup*

Run :JlsInstall once after installing the plugin. JLS is downloaded to
Neovim's data directory. Use setup() only to override defaults.

>
  require("jls").setup({})
<

JLS starts automatically on FileType=java via a filetype plugin.

DISK USAGE~

*jls-disk-usage*

This plugin writes to two locations:

JLS binary:
  stdpath("data")/jls/
  Typically ~/.local/share/nvim/jls/ on Linux/macOS,
  ~/AppData/Local/nvim-data/jls/ on Windows.
  Remove by deleting the directory manually.

Workspace cache:
  $XDG_CACHE_HOME/jls/<project>-<hash>/
  Typically ~/.cache/jls/ on Linux/macOS.
  Remove per-workspace with :JlsClearCache, or delete ~/.cache/jls/ manually.

COMMANDS~

*jls-commands*

:JlsInstall [tag]
                Download and install JLS. Uses latest release by default.
                Pass a version tag (e.g. v1.2.3) to install a specific version.
:JlsUpdate      Update JLS to the latest release.
:JlsRestart     Restart JLS. Only available while JLS is running.
:JlsLog         Open Neovim's LSP log in a read-only buffer.
:JlsClearCache  Delete this workspace's JLS disk cache.
:checkhealth jls
                Run the built-in health check for nvim-jls.

CONFIGURATION~

*jls-configuration*

>
  require("jls").setup({
    jls_dir = nil,
    settings = {},
    root_markers = {
      "pom.xml",
      "build.gradle",
      "build.gradle.kts",
      "settings.gradle",
      "settings.gradle.kts",
      "WORKSPACE",
      "WORKSPACE.bazel",
      ".java-version",
      ".git",
    },
    inlay_hints = {
      enabled = false,
    },
    jvm_args = nil,
    cmd_env = {},
    auto_restart = false,
  })
<

JVM memory defaults: -Xmx2g -Xms512m -XX:MaxHeapFreeRatio=50
-XX:MinHeapFreeRatio=20 -XX:+UseStringDeduplication. Override via jvm_args:

>
  require("jls").setup({
    jvm_args = { "-Xmx1g", "-Xms256m" },
  })
<

The list is joined and passed as JLS_JVM_OPTS to the launcher. You can also set
the env var directly: export JLS_JVM_OPTS="-Xmx1g".

cmd_env passes arbitrary environment variables to the JLS process:

>
  require("jls").setup({
    cmd_env = { JAVA_HOME = "/usr/local/java21" },
  })
<

auto_restart automatically restarts JLS if it exits unexpectedly, up to 3
attempts with exponential backoff. Disabled by default.

>
  require("jls").setup({
    auto_restart = true,
  })
<


INLAY HINTS~

*jls-inlay-hints*

Enable parameter name hints at call sites:

>
  require("jls").setup({
    inlay_hints = { enabled = true },
  })
<

Hints appear only for files in your workspace. JDK and dependency sources
opened via go-to-definition are not annotated.

CODE ACTIONS~

*jls-code-actions*

Use the standard Neovim LSP mapping (vim.lsp.buf.code_action()) to trigger
code actions. Actions are computed lazily — the list appears immediately, and
the workspace edit is only computed when you confirm an action.

On a text selection inside a method:
  - Surround with try-catch
  - Extract to local variable

With cursor inside a class (no selection):
  - Generate constructor / equals / hashCode / toString
  - Generate getters (pick fields) — opens a picker
  - Generate setters (pick fields) — opens a picker; final fields are excluded
  - Override inherited method — one entry per overridable method
  - Add @Lombok annotation — available when Lombok is on the classpath

Quick fixes (from diagnostics):
  - Import unresolved type
  - Add throws for unreported exception
  - Implement abstract methods
  - Generate constructor (missing field initializer)
  - Create missing method
  - Remove unused class / method / field / local variable
  - Remove unused throws clause
  - Suppress unchecked warning

Getter/setter picker: when snacks.nvim is loaded, a multi-select picker opens
(<Tab> to select, <CR> to confirm). Without snacks.nvim, a floating window
lists fields and vim.ui.input prompts for comma-separated numbers or "all".

RENAME~

*jls-rename*

Use the standard Neovim rename (vim.lsp.buf.rename()). When renaming a class,
JLS also renames the source file on disk and refreshes your file explorer
automatically (nvim-tree, neo-tree, mini.files, and snacks.nvim are supported).
