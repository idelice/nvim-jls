*jls.txt*  Neovim integration for JLS

*jls*

INTRODUCTION~

*jls-introduction*

nvim-jls provides Neovim integration for JLS (Java Language Server), with
OS-aware launcher resolution and stable root detection.

REQUIREMENTS~

*jls-requirements*

- Neovim 0.9+ (0.10+ recommended)
- JLS installed locally with a dist/ folder
- Optional: nvim-lspconfig

SETUP~

*jls-setup*

>
  require("jls").setup({
    jls_dir = "/path/to/jls",
    settings = {},
  })
<

JLS starts automatically on FileType=java via a filetype plugin. Use setup()
only if you want to override defaults.

COMMANDS~

*jls-commands*

:JlsStart       Start JLS for the current buffer.
:JlsRestart     Restart JLS.
:JlsStop        Stop all running JLS clients.
:JlsDoctor      Show effective config and diagnostics.

CONFIGURATION~

*jls-configuration*

>
  require("jls").setup({
    jls_dir = nil,
    settings = {},
    root_markers = {
      "pom.xml",
      "build.gradle",
      "build.gradle.kts",
      "settings.gradle",
      "settings.gradle.kts",
      "WORKSPACE",
      "WORKSPACE.bazel",
      ".java-version",
      ".git",
    },
  })
<

nvim-jls does not choose the server JVM. It launches the packaged JLS launcher
and passes through any LSP settings you configure. The current JLS distribution
is built for Java 25 and runs on its packaged Java 25 runtime.

`settings.java.configuration.runtimes` may still be sent to JLS in the LSP
configuration payload, but nvim-jls does not use that list to decide how the
server process is started.
