*jls.txt*  Neovim integration for JLS

*jls*

INTRODUCTION~

*jls-introduction*

nvim-jls provides Neovim integration for JLS (Java Language Server), with
OS-aware launcher resolution and stable root detection.

REQUIREMENTS~

*jls-requirements*

- Neovim 0.9+ (0.10+ recommended)
- JLS installed locally with a dist/ folder
- Optional: nvim-lspconfig

SETUP~

*jls-setup*

>
  require("jls").setup({
    jls_dir = "/path/to/jls",
  })
<

JLS starts automatically on FileType=java via a filetype plugin. Use setup()
only if you want to override defaults.

COMMANDS~

*jls-commands*

:JlsStart       Start JLS for the current buffer.
:JlsRestart     Restart JLS.
:JlsStop        Stop all running JLS clients.
:JlsDoctor      Show effective config and diagnostics.

CONFIGURATION~

*jls-configuration*

>
  require("jls").setup({
    jls_dir = nil,
    filetypes = { "java" },
    debounce_text_changes = 200,
    inlay_hints = false,
    inlay_hints_refresh = "auto",
    inlay_hints_debounce_ms = 120,
    codelens = false,
    root_markers = {
      "pom.xml",
      "build.gradle",
      "build.gradle.kts",
      "settings.gradle",
      "settings.gradle.kts",
      "WORKSPACE",
      "WORKSPACE.bazel",
      ".java-version",
      ".git",
    },
  })
<

INLAY HINTS~

`inlay_hints` can be `true` (enable with server defaults) or a table forwarded to
`settings.java.inlayHints`:

>
  require("jls").setup({
    inlay_hints = {
      enabled = true,
      parameterNames = true,
      debounceMs = 250,
      cacheIdleMs = 120000,
      cacheMaxEntries = 256,
    },
  })
<

`inlay_hints_refresh` controls client-side inlay hint update behavior:
- `"auto"`: use Neovim's default refresh behavior.
- `"insert_leave"`: disable hints while typing and refresh after leaving insert mode.

`inlay_hints_debounce_ms` sets the delayed refresh in milliseconds when using
`"insert_leave"` mode.
